# Origen Alto · Café de especialidad

Proyecto académico de eCommerce creado por **Jann Romero**, a partir de una tienda base de CodePen.

**Tienda en línea:** https://papol123.github.io/romero_jann_ecommerce_origen_alto/

## Concepto
- **Qué vende:** café de especialidad colombiano y accesorios para prepararlo en casa.
- **Slogan:** "Del cafetal a tu taza, sin escalas."
- **eShopper:** universitarios y jóvenes profesionales de Bogotá (18–30 años) que toman café a diario, estudian o trabajan desde casa y quieren pasar del café de sobre a uno de mejor calidad, a buen precio y con entrega rápida.

## Cambios frente a la tienda base
- Nuevo nombre, slogan e identidad visual (paleta espresso, crema, terracota y verde cafetal).
- Catálogo de 8 productos: 5 transformados y 3 nuevos, con precios en COP.
- Imágenes ilustradas en SVG dentro del código, para que siempre carguen.
- Carrito con botones + / − para modificar cantidades y mensaje de carrito vacío.
